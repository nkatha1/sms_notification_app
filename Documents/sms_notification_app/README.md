## 🧭 Project Setup

1. **Clone the repository:**
    ```bash
    git clone https://github.com/nkatha1/sms_notification_app.git
    ```

2. **Navigate to the project:**
    ```bash
    cd sms_notification_app/Documents/sms_notification_app
    ```

3. **Install dependencies** (if applicable):
    ```bash
    # Example for Node.js
    npm install
    ```

4. **Configure Environment Variables:**
    Create a `.env` file and add:
    ```env
    SMS_API_KEY=YOUR_API_KEY
    SMS_SENDER_NUMBER=YOUR_PHONE_NUMBER
    ```

5. **Run the app:**
    ```bash
    npm start
    ```
    or the run command specific to your project
